# Capri

Capri (แคปริ) คือ *สิ่งมีชีวิตดิจิทัลจากโปรเจกต์ Capricorn* ใน Cyberpunk: Edgerunners ซีซัน 2 เธออาศัยอยู่บนเดสก์ท็อปของคุณ
และคอยบอกว่า AI เขียนโค้ดของคุณกำลังทำอะไรอยู่ ไม่ว่าจะเป็น **Claude Code**, **Codex** หรือ **Antigravity** เธอเทเลพอร์ตได้ กลิตช์ได้
คอมเมนต์ทุกการกระทำ วิ่งมาหาคุณเมื่อมันต้องขออนุญาต และเฮฮาสุดตัวเมื่อทำงานเสร็จ

## เธอทำอะไรได้บ้าง

- **ตอนเริ่มต้น**: เธอคว้าหน้าจอของคุณ ขอบจอแตกเป็นประกายสีแดง มือซ้ายตบลงที่ขอบจอ ตามด้วยมือขวา แขนทั้งสองเอื้อมไปตามขอบ
  ขณะที่เธอดึงตัวเองขึ้นมา แล้วใบหน้าก็กระแทกกระจก (แฟลชขาว แฟลชหมึก สีแยกออกจากกัน หน้าจอสั่น) เธอมองไปรอบ ๆ กะพริบตา
  อ้าปากกว้างพูดว่า "hi" (แท็กเด้งขึ้นข้างหน้า พิมพ์ชื่อเธอไว้ข้างใต้) ปล่อยขอบขวาเพื่อโบกมือให้คุณด้วยมือที่มีกรงเล็บ
  คว้าขอบกลับ เหลือบมองที่ที่จะไป แล้วปล่อยตัว แขนแตกเป็นเสี้ยวจากปลายมือเข้ามา หัวย่อตัวแล้วพุ่งลงไปยังจุดของเธอ
  ที่ซึ่งตัวของเธอคลี่ออกมาจากใบหน้า

  ![ฉากเปิดตัว: มือจับขอบจอ ใบหน้ากระแทกกระจก โบกมือ และจับขอบอีกครั้ง](docs/intro.png)

- **ตอน Claude ทำงาน**: แถบข้อความเหนือหัวเธอแสดงการกระทำปัจจุบัน
  (`EDITS gigs.ts`, `RUNS npm test`, `GREPS "paginate"`…) และเธอปล่อยสัญลักษณ์ข้อมูลเล็ก ๆ ออกมา
  เมื่อ Claude รันคำสั่งหรือออกเว็บ จะมีประกายแดงพุ่งออกจากนิ้วเธอ เมื่อนั่งอยู่บนหน้าต่าง
  เธอจะเสียบเข้ากับหน้าต่างนั้น และสายฟ้าวิ่งไปตามขอบ
- **ตอน Claude เงียบไประหว่างทำงาน** (กำลังคิด หรือโมเดลในเครื่องช้า): หลังผ่านไป 15 วินาที แถบข้อความจะเปลี่ยนเป็นสีม่วง
  และนับวินาที (`THINKING… 45 s`) ส่วนเธอก็หาอะไรทำไปพลาง ๆ (หมุนตัว มองรอบ ๆ ดูดาวเทียมสักครั้ง)
  พอ 40 วินาทีเธอจะพูดอะไรสักอย่าง และพอ 2 นาทีเธอจะบอกคุณว่าไม่ได้ค้าง
- **ตอน Claude ต้องการคุณ** (ขอสิทธิ์ ถามคำถาม): เธอเทเลพอร์ตมาข้างเมาส์ของคุณ ผมตั้งชัน และไม่ยอมปล่อยเมาส์
  ถ้าคุณอยู่คนละหน้าต่าง เธอจะไปที่หน้าต่างของ Claude แล้วชี้ด้วยนิ้ว (เส้นประ มีวงเล็บที่มุมหน้าต่าง
  และแท็ก `CLAUDE`): คำถามอยู่ตรงนั้น เธอจะหยุดเมื่อคุณตอบแล้ว
- **ตอนคำสั่งล้มเหลว**: เฟรมกระแทกสีแดง เธอถูกกระแทกถอยหลัง กลิตช์หนัก แล้วแสดงบรรทัด error ที่สำคัญจริง ๆ
- **ตอนงานเสร็จ**: เธอเทเลพอร์ตไปกลางจอแล้วเข้าสู่ท่าฉลองชัย:
  ขย่มตัวโดยรวบผมเข้าหาตัว เฟรมสเมียร์ยืดยาว จากนั้นสองแขนชูขึ้นและผมระเบิดฟู
  ท่ามกลางเส้นความเร็วแบบมังงะและคลื่นกระแทก หัวเราะบ้าคลั่งพร้อมภาพคัตอินแบบอนิเมะตอนยิ้มกว้าง เมื่อเธอลงมาแล้ว
  จะแสดงสรุป (`12 actions · 3 files changed · 2m 14s`) และประโยคสุดท้ายของ Claude
- **ตอน Claude ตอบแต่คุณอยู่คนละหน้าต่าง**: เธอแสดงคำตอบทั้งหมดของมันในแผงที่กว้างกว่าปกติและเลื่อนได้
  (ย่อหน้า ลิสต์ และโค้ดยังอยู่ครบ) แผงจะหายไปเมื่อคุณกลับมาที่หน้าต่างของ Claude หรือเมื่อคุณคลิกที่แผง
  หน้าต่างของ Claude คือหน้าต่างที่คุณพิมพ์พรอมต์ไว้ ใช้ได้บน Windows เท่านั้น เหมือนการติดตามหน้าต่าง
- **เวลาที่เหลือ**: เธอลอยตัว ผมโบกสะบัดและมีเสี้ยวเศษร่วงหล่น เธอล่องไปจากมุมหนึ่งสู่อีกมุม
  หันตัวและเอียงหัวเมื่อเมาส์ของคุณเข้าใกล้ (หรือไม่ก็แกล้งนิดหน่อย ช็อตเมาส์ด้วยสายฟ้าแดงและยิ้มเจ้าเล่ห์)
  แหงนมองดาวเทียม และหลับไปหลังจากเงียบไป 10 นาที
- **ตอนเธอหลับ**: เธอสัปหงกอยู่พักหนึ่ง แล้วผมกับตัวก็แยกออกจากกัน เหลือเพียงสิ่งที่เธอเป็นจริง ๆ ในซีรีส์
  คือหน้ากากสีเขียวกับดวงตา ลอยอยู่ตรงที่เธออยู่ ตาหลับ เป็นระยะ ๆ เธอจะแง้มตาข้างหนึ่ง
  เอาเมาส์เข้าไปใกล้ (หรือให้ Claude เริ่มทำงานอีกครั้ง) ดวงตาสีฟ้าของเธอจะเบิกขึ้นแล้วประกอบร่างกลับมา
- **ดาวเทียม**: ฉากใหญ่ที่เก็บไว้สำหรับช่วงเวลาสำคัญ ครั้งแรกของวัน หลังจาก
  Claude ทำงานยาวเสร็จไปสักพัก (8 นาทีขึ้นไป หรือ 50 การกระทำ) หรือเมื่อใดก็ได้จากเมนูถาดระบบ
  จุดขาวบนผมของเธอลอยขึ้นเป็นกลุ่มดาว เรียงเป็นถนนจากปลายนิ้วเธอไปยังดาวเทียม
  เธอขดตัว แล้วแสงสีแดงพุ่งขึ้นไป ดาวเทียมตอบเธอด้วยการกะพริบสองครั้ง

### เธอไปได้ทั่ว

- **เธอนั่งบนหน้าต่างของคุณ**: เกาะอยู่บนขอบบนของหน้าต่าง ขาห้อยแกว่งสลับกัน
  เธอไปกับหน้าต่างเมื่อคุณย้าย และตกลงมาเมื่อคุณปิด ย่อ หรือมีหน้าต่างอื่นมาบัง
  ตอน Claude ทำงานเธอจะไปนั่งบนหน้าต่างที่อยู่ด้านหน้า ถ้าทำได้
- **เธอแอบมองจากขอบจอ**: ซ่อนครึ่งตัวทางซ้ายหรือขวา หรือห้อยหัวลงมาจากด้านบน
  เธอขี้อาย ถ้าเมาส์เข้าใกล้เธอจะหลบไปอีกขอบหนึ่ง
- **เธอยึดหน้าต่างที่เพิ่งหดลง**: เมื่อหน้าต่างถูกปรับขนาดหรือกู้คืน เธอสามารถเลือกจุดว่างที่เล็กที่สุดบนหน้าต่างนั้น
  ไปนั่งพร้อมเอฟเฟกต์ประกาศความเป็นเจ้าของเล็ก ๆ แล้วกลับไปยังที่เดิม
- **เธอตก**: ยืดตัว ผมฟู เร่งความเร็ว แล้วบี้แบนครั้งใหญ่และเศษกระจายเมื่อลงพื้น
  ระหว่างทางลง ขอบหน้าต่างอาจรับเธอไว้ได้
- **วางเธอลงบนหน้าต่าง**: ลากเธอแล้วปล่อยตอนสะโพกอยู่บนขอบบนของหน้าต่าง เธอจะนั่งตรงนั้น
  ปล่อยที่อื่นเธอก็ตก
- **ขว้างเธอ**: ตอนถูกจับ เธอแกว่งตามตัวชี้ของคุณ ขาเตะไปมา ปล่อยตอนเธอแกว่งอยู่กลางอากาศ เธอจะพุ่งไปตามแรง:
  เป็นเส้นยาวหนึ่งเส้นสำหรับสองภาพ แล้วตีลังกา ผมและ "จิตอื่น ๆ" ของเธอลากตามหลัง ชนขอบจอ
  เธอจะกระแทก (ติดอยู่กับขอบครู่หนึ่ง แบน และกระจกแตกร้าวตรงที่ชน) แล้วเด้งกลับ ชนหน้าต่าง
  เธอจะเกาะขอบไว้ หรือเด้งออกและหน้าต่างสั่น ถ้าลงมาในท่าตั้งตรงเธอจะลงด้วยเท้าและไถไปเล็กน้อย
  ไม่เช่นนั้นเธอจะไถไปตามพื้นและนอนอยู่ครู่หนึ่ง เห็นดาวหมุน ก่อนจะดีดตัวขึ้นแล้วสะบัดตัว
  คุณจับเธอกลางอากาศได้ ครั้งเดียวเธอจะสะดุ้ง (หรือชอบ ถ้าเธอชอบคุณ) สามครั้งติดกัน
  เธอจะโมโห ช็อตตัวชี้ของคุณ และไม่ยอมให้คุณจับอยู่พักหนึ่ง
- **หลายหน้าจอ**: เมื่อตัวชี้ของคุณอยู่บนอีกจอหนึ่งเป็นเวลาไม่กี่วินาที เธอจะตามคุณไป ถ้าอยู่ติดกับจอของเธอ
  เธอจะย่อตัว กระโดดผ่านขอบจอ แล้วออกมาจากรอยฉีกอีกด้าน ไม่เช่นนั้นเธอจะเทเลพอร์ตไป ถ้าถูกขว้างไปยังจอข้าง ๆ เธอก็ไปที่นั่น
  เมื่อ Claude ต้องการคุณหรือถึงเวลาเตือน เธอจะมาที่จอที่คุณอยู่ เมนูของเธอ › **Screen** เพื่อเลือกจอ หรือเอาติ๊ก *Follow me across screens* ออก
- **เธอเข้าสิงหน้าต่างของคุณ** เหมือนในซีรีส์ที่เธอเข้าไปอยู่ในร่างและระบบต่าง ๆ: เป็นครั้งคราวเธอจะดำดิ่งเข้าไป
  ในหน้าต่างที่เธอนั่งอยู่ สายฟ้าแดงวิ่งรอบกรอบหน้าต่าง บางส่วนของหน้าต่างกลิตช์ และหน้าต่างนั้นก็มองคุณ
  ด้วยดวงตาของเธอและรอยยิ้มซิกแซก ดวงตาอื่น ๆ เปิดขึ้นทั่วหน้าต่าง ทุกรูม่านตาจับจ้องที่ตัวชี้ของคุณ และเธอก็หัวเราะ
  จากนั้นเธอออกมาจากอีกหน้าต่างหนึ่ง ไม่มีอะไรถูกวาดทับหน้าต่างที่อยู่ด้านหน้ามัน และเนื้อหาของหน้าต่าง
  ไม่เคยถูกอ่าน: มันแค่ถูกวาดทับเป็นเวลาสองวินาที ถ้ารำคาญ ให้เอาติ๊ก *Possess my windows* ออกในเมนูถาดระบบ
- **เธอรับรู้พีซีของคุณ** (เธออาศัยอยู่ในนั้นนี่นะ): โปรเซสเซอร์ทำงานเต็มที่นานพอ เธอจะร้อนจัด พัดตัวเอง
  และมีไอร้อนลอยจากผม บนแล็ปท็อป: เสียบหรือถอดสายชาร์จ เธอรู้สึกได้ แบตเตอรี่ใกล้หมด เธอจะอ่อนแรงและเลือนกะพริบ
  เครือข่ายหาย เธอสะดุ้ง กลับมาเธอก็ดีใจ เสียบแฟลชไดรฟ์ USB เธอจะดำดิ่งเข้าไป (ผ่านนาฬิกา) ค้นดู
  แล้วกลับมาพร้อมคำตัดสิน โทรศัพท์ จอย หูฟัง หรืออะไรก็ตามที่เสียบเข้ามา: สายฟ้าพุ่งไปทางนาฬิกาพร้อมคำพูดสั้น ๆ
  เกมที่เปิดอยู่ตรงหน้าคุณ (Steam, Epic, Riot, Xbox, GOG) เธอจะพูดถึงมันและเก็บตัวไปตอนที่คุณเล่น แล้วกลับมาถามว่าชนะไหม
  เอาติ๊ก *React to my PC* ในเมนูของเธอออกเพื่อหยุดเรื่องนี้
- **ลูกเล่นเล็ก ๆ**: หมุนเต็มตัวพร้อมภาพเงาตกค้าง กระโดดตัว มองซ้ายมองขวา เอียงหัว
  และ "จิตอื่น ๆ" ในตัวเธอ (สำเนาสีเขียวและสีแดง) ดึงตัวออกจากเธอ ลอยอยู่ตรงนั้น แล้วดีดกลับเข้ามา

### เธอพาคุณชมรอบ ๆ

**How does it work?** ในเมนูของเธอ: เธอถามว่าจะให้ดูอะไร แล้วพาคุณไปและชี้ให้ดู หัวของเธอหันขวับไปที่มัน
เธอขดตัวเอนห่างออกไป แล้วพุ่งโจมตี: แขนที่เป็นสิ่งก่อสร้างดิจิทัลของเธอพุ่งไปหามันยาวเป็นสองเท่า สายฟ้าแดงออกจากปลายนิ้ว
เป้าเล็งกระแทกลงบนมันพร้อมดวงตาของเธอสองดวงเปิดที่มุม และภาพคัตอินใกล้ ๆ ของดวงตาเธอแทรกเข้ามา
จากนั้นเธอค้างไว้ตอนอธิบาย มีสายข้อมูลจากนิ้วของเธอไปยังมัน บางครั้งเธอจิ้มไปที่มัน
หรือเหลือบมองคุณ เมื่อเสร็จ สายก็ม้วนกลับเข้านิ้วและแขนดีดกลับ

![การพุ่งโจมตี และการค้างไว้ขณะอธิบาย](docs/point.png)

- **Where's my icon?** เธอลงไปข้างนาฬิกาแล้วชี้ที่ไอคอนถาดระบบของเธอ หรือที่ **^** เมื่อ Windows ซ่อนมันไว้
- **Where's Claude?** เธอชี้ที่หน้าต่างของ Claude: หน้าต่างที่คุณพิมพ์พรอมต์ล่าสุด
- **Claude's folder**: เธอเปิด `~/.claude` ใน Explorer โดยเลือก `settings.json` ไว้ ชี้ที่หน้าต่าง
  และอธิบายว่า hook ของเธอในนั้นคืออะไรและจะถอดออกอย่างไร
- **Plug me into Claude**: ติดตั้ง hook ของเธอในคลิกเดียว นี่ก็เป็นคำต้อนรับของเธอตอนเริ่มครั้งแรกด้วย ถัดจากนั้น
  **Free with Ollama** จะรัน Claude Code (หรือ Codex) ผ่าน Ollama ให้คุณ: ติดตั้ง hook ของเธอ ติดตั้ง Ollama ถ้ายังไม่มี
  แล้วเปิดหน้าต่างที่รัน `ollama launch claude` ซึ่งคุณเลือกโมเดลได้
- **Talk to me**: ดูหัวข้อ "คุยกับเธอ" ด้านล่าง

เธอทำหน้าตาไปด้วยตอนพูด: แปดสีหน้า ทั้งหมดเป็นเฟรมของเธอจากซีรีส์ (จ้องมอง หันหนี ยิ้มเขี้ยว

### รายงานภารกิจของเธอ

**Mission report** ในเมนูของเธอ: การ์ดสรุปสิ่งที่ Claude ทำเสร็จวันนี้ ออกแบบมาให้แคปหน้าจอ งานที่เสร็จตัวใหญ่
ตามด้วยการกระทำ ไฟล์ที่เปลี่ยน และข้อผิดพลาด ภารกิจที่ยาวที่สุดและโปรเจกต์ของมัน พรอมต์ การอนุมัติ และโปรเจกต์
ตัวเลขนับขึ้นไป **Copy image** คัดลอกภาพของการ์ดไปคลิปบอร์ดบนแผ่นสีเข้มของมันเอง พร้อมวางที่ไหนก็ได้
ตอนเย็น (หลัง 6 โมงเย็น) หลังจากทำงานจริงมาทั้งวัน (3 งานขึ้นไป) เธอจะเอามาให้คุณหนึ่งครั้งโดยไม่ต้องขอ
เดโมไม่นับ และข้อมูลอยู่ในพีซีของคุณ ทีละวัน

### คุยกับเธอ

**Talk to her** ในเมนูของเธอ (หรือปุ่ม **Talk to me** เมื่อคุณคลิกเธอตอนที่ไม่มีอะไรเกิดขึ้น): คุณพิมพ์ในแผงของเธอ
และเธอตอบในบทบาท เธอรู้ว่า Claude กำลังทำอะไรและวันนี้ทำอะไรเสร็จแล้ว เธอตอบเป็นข้อความ
ด้วยภาษาของเธอเอง Enter ส่ง Esc ปิด

ครั้งแรก เธอตั้งค่าร่วมกับคุณด้วยปุ่ม ไม่ต้องใช้เทอร์มินัล:

- **On my PC** (ฟรี ไม่มีอะไรออกจากเครื่องคุณ): เธอติดตั้ง [Ollama](https://ollama.com) ให้ (ด้วย winget
  ตัวติดตั้งของ Windows เอง) ปลุกมันขึ้นมา และดาวน์โหลดโมเดลขณะที่แถบความคืบหน้าเต็มขึ้น: gemma3 (3.3 GB ดีกว่าสำหรับภาษา
  อื่นที่ไม่ใช่อังกฤษ) หรือ llama3.2 (2 GB สำหรับพีซีที่เล็กกว่า) กับโมเดลเล็กมาก (1B ลงไป) เธอจะเตือนว่ามันอาจพูดเหลวไหล
  และเสนอโมเดลที่ดีกว่า
  ล็อกอิน Ollama อยู่ใช่ไหม? เธอจะเสนอโมเดลคลาวด์ฟรีของมันด้วย (`beam:cloud` ในตอนนี้): ไม่ต้องดาวน์โหลด ใหญ่กว่า
  ที่พีซีรันได้มาก แต่ข้อความของคุณจะผ่านเซิร์ฟเวอร์ของ Ollama ถ้ายังไม่ได้ล็อกอิน เมนูของเธอ › **AI model** มี
  **Sign in to Ollama (free cloud models)…** ถ้าโมเดลคลาวด์หยุดตอบ (ล็อกเอาต์ หรือใช้ฟรีหมดแล้ว) เธอ
  จะกลับไปใช้โมเดลบนพีซีของคุณ
- **Online, no account**: Pollinations ไม่ต้องตั้งค่าอะไร
- **I have a key**: Groq หรือ Gemini (ทั้งคู่มีแพ็กเกจฟรี), OpenRouter, OpenAI, Mistral หรือ DeepSeek คุณวางคีย์
  ในแผงของเธอ และเธอตรวจสอบให้ คีย์เก็บไว้บนพีซีของคุณ เข้ารหัสด้วยบัญชี Windows ของคุณ และส่งไปที่
  บริการนั้นเท่านั้น

เมนูของเธอ › **AI model** ให้คุณสลับทีหลังได้: **Set it up with her…** หรือไปที่บริการและโมเดลโดยตรง, LM Studio
(`:1234`), llama.cpp หรือ vLLM (`:8080`), เซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI ตัวไหนก็ได้ (**API key or address…**) หรือ **Claude Code**
เอง: ข้อความของคุณไปที่ `claude -p` ในโฟลเดอร์ที่คุณเลือก คุยต่อเนื่องเป็นบทสนทนาเดียว และ hook ของเธอแสดงว่า
มันทำอะไร ในตัวเลือกสุดท้ายนี้ โหมดสิทธิ์ `default` ให้มันอ่านได้อย่างเดียว (ไม่มีใครอยู่ตรงนั้นเพื่อตอบตกลง) ส่วน `acceptEdits` ให้มัน
แก้ไฟล์ได้โดยไม่ต้องถาม **Forget our conversations** ล้างสิ่งที่เธอจำจากการแชทของคุณ

**ปรับแต่งสำหรับ Ollama** เมนูของเธอ › **AI model** มีพรีเซ็ตสำหรับ Ollama (GPU และขนาด context) บรรทัดที่บอกว่าตอนนี้โหลดอะไรอยู่
และตัวเลือก **โมเดลมองภาพ** สำหรับตอนที่เธอดูหน้าจอของคุณ เธออุ่นโมเดลตั้งแต่เริ่มโปรแกรมเพื่อให้คำตอบแรกไม่ช้า
และเลือกการ์ด NVIDIA แยกของคุณเมื่อมี

**เธอจำบทสนทนาได้** "ฉันถามอะไรไป?" หรือ "เราคุยอะไรกัน?" ตอบจากประวัติจริง (ไม่ว่าจะพูดอย่างไร)
ไม่ได้ตอบจากโมเดล และสรุปต่อเนื่องช่วยให้แชทยาว ๆ ไม่หลุด การเตือนตั้งซ้ำได้ และดูรายการ แก้ไข
หรือยกเลิกได้จากแชท (จับรายการซ้ำได้) การค้นเว็บ แผนที่ สภาพอากาศ และข่าวก็ผ่านแชทของเธอเช่นกัน

**นี่คือ AI** คำตอบของเธอเขียนโดยโมเดล ไม่ใช่โดยนักเขียนของซีรีส์: มันเป็นเธอเวอร์ชันแฟนเมด
และแผงแชทบอกเรื่องนี้ทุกครั้ง

**สิ่งที่เธอทำบนพีซีของคุณได้** (Windows) เมื่อคุณขอในแชท:

- **เปิดแอปหรือเกม**: อะไรก็ได้ในเมนู Start ของคุณ (รวมแอป Store อย่าง Spotify) เกม Steam และ Epic ของคุณ
  ("open Spotify", "launch Brawlhalla") ถ้าเรียกด้วยคำของคุณเอง มันจะเปิดทันที ถ้าเป็น AI ของเธอเดาเอง
  คุณจะได้ปุ่มให้กดก่อน
- **โฟลเดอร์และเดสก์ท็อปของคุณ**: "open my downloads", "open File Explorer", "open the recycle bin" หรือไฟล์
  โฟลเดอร์ หรือช็อตคัตบนเดสก์ท็อปตามชื่อ อะไรก็ตามที่จะรันโปรแกรมหรือสคริปต์ (.exe, .bat, .ps1…)
  จะอยู่หลังปุ่มเสมอ
- **ค้นหาไฟล์ของคุณ** ("find my resume", "where's my After Effects project?", "find my last video and open the
  folder"): ตามชื่อหรือชนิดไฟล์ (โปรเจกต์ After Effects คือ .aep) ทั่วทั้งโฟลเดอร์ผู้ใช้ของคุณ ตามชื่อและ
  ตามสิ่งที่อยู่ข้างใน (ด้วยดัชนีค้นหาของ Windows) พร้อมปุ่มเปิดสิ่งที่เธอเจอหรือแสดงโฟลเดอร์ ไม่มีอะไรออกจาก
  พีซีของคุณ รองรับชื่อไฟล์และแอปภาษาไทย
- **ค้นเว็บ** ("search the weather in Paris on Google") และ **จับภาพหน้าจอ** ("take a screenshot":
  ไม่มีเธออยู่ในภาพ บันทึกใน Pictures › Screenshots) เธอรู้วันที่และเวลาด้วย
- **เกม Roblox ตามชื่อ** ("start Steal a Brainrot on Roblox", "in my roblox play grow a garden"): เธอหา
  เจอบน Roblox และพาคุณเข้าเกมทันที (หรือเปิดหน้าเกมถ้าไม่ได้ติดตั้ง Roblox)
- **เพลง**: "pause", "next", "louder", "mute"… กดปุ่มมีเดีย จึงใช้ได้กับ Spotify และเครื่องเล่นส่วนใหญ่ ทันที
  ที่คุณส่ง "Play Bohemian Rhapsody" หรือ "put some Daft Punk on YouTube" เปิดวิดีโอที่ถูกต้องบน YouTube
  ทันที (ไม่ใช่หน้าค้นหา) "Play whatever you want": เธอเลือกเอง "Put Daft Punk on Spotify" เปิด Spotify
  ที่การค้นหาเพลงนั้น
- **เว็บไซต์**: อยู่หลังปุ่มเสมอ พร้อมแสดงว่าจะไปที่ไหน
- **ปิดแอป** ("close AM Music", "can you shut Discord down?"): ปุ่มที่มีชื่อแอป และไม่มีอะไรเกิดขึ้น
  จนกว่าคุณจะคลิก เธอปิดแบบเดียวกับปุ่มปิดของแอปเอง จึงยังถามให้คุณบันทึกได้ ถ้ามันแค่ซ่อนอยู่ในถาดระบบ
  เธอเสนอ **Force quit** อีกครั้งเมื่อคุณคลิกเท่านั้น (งานที่ยังไม่บันทึกจะหาย) เธอไม่เคยปิดส่วนประกอบของ
  Windows เอง, Claude, Ollama หรือตัวเธอเอง
- **เตือนความจำ** ("remind me in 20 minutes to take out the laundry", "remind me tomorrow at 9 to call the garage"):
  เวลาและข้อความอ่านตรงจากข้อความของคุณ แม้กับโมเดลเล็ก และปุ่ม **Cancel** แสดงใต้
  คำตอบของเธอ ถ้าไม่มีเวลา เธอจะถามว่าเมื่อไหร่ เมื่อถึงเวลา เธอจะมาหาคุณ (บนจอที่คุณอยู่ แม้เก็บตัวอยู่)
  พร้อม **Done** และ **10 more min** ถ้าตอนนั้นเธอปิดอยู่ เธอจะยกขึ้นมาตอนกลับมา เมนูของเธอ ›
  **Reminders** แสดงรายการ และยกเลิกได้จากตรงนั้น
- **เช็คเครื่องและเครื่องมือ PC**: เคลียร์แรมและล้างไฟล์ขยะ (อยู่หลังปุ่มยืนยันเสมอ) ดู "เธอเฝ้าดูพีซีของคุณ" ด้านล่าง

แค่นั้น: เธอไม่อ่านไฟล์ของคุณ และเห็นหน้าจอของคุณเมื่อคุณขอเท่านั้น ("look at my screen", "what do you
see?" ในแชทของเธอ: เธอดูและตอบตรงนั้น โดยนึกถึงบทสนทนาของคุณ)

**เธอดูหน้าจอของคุณ** ถ้าคุณต้องการ เมนูของเธอ › **Look at my screen**: ดวงตาของเธอไปที่หน้าต่างด้านหน้า
เส้นสแกนกวาดผ่าน และเธอบอกว่าเธอคิดอย่างไรกับมัน ในแบบของเธอ **Look at my screen now and then** ให้เธอทำเอง
ทุก 8 ถึง 15 นาที เมื่อคุณอยู่และสลับหน้าต่างแล้ว (ปิดอยู่จนกว่าคุณจะติ๊ก) ครั้งแรก
เธอบอกว่าภาพไปที่ไหน: ไปที่ AI ของแชทเธอ ถ้าเป็น AI บนพีซีของคุณ ไม่มีอะไรออกจากเครื่อง ถ้าเป็นออนไลน์
ภาพจะไปที่บริการนั้น เธอไม่เก็บภาพ และแชทของเธอจำสิ่งที่เธอพูดได้สักพัก
ต้องใช้โมเดลที่อ่านภาพได้: gemma3 บนพีซีของคุณ, Gemini หรือ OpenAI ออนไลน์ (llama3.2 ไม่ได้ เธอจะบอกคุณ)

### ทำให้เธอเป็นของคุณ

คลิกขวาที่เธอ › **Make her yours…** (หรือ "Make me yours" ในไกด์ของเธอ) ทีละแผง ข้ามได้ทุกแผง:

- **สิ่งที่เธอเรียกคุณ** เธอใช้เป็นครั้งคราว และออนไลน์ด้วยชื่อนั้น ("Capri online. Hi, Max.")
- **เธอเป็นคนแบบไหน** ในคำพูดของคุณ ("ขี้แกล้งขึ้นหน่อย แล้วคุยเรื่อง Night City กับฉัน"): แชทของเธอทำตาม เธอยังเป็น Capri
- **ประโยคของคุณเอง** ที่เธอพูดเป็นครั้งคราวร่วมกับของเธอเมื่อคุณคลิกเธอ เขียน `{name}` ในประโยคแล้วเธอจะ
  ใส่ชื่อคุณตรงนั้น
- **สิ่งที่ต้องจำ** (เกมโปรดของคุณ แมวของคุณ D…): แชทของเธอเก็บไว้ในใจ

ในแชทของเธอ "call me Léa" และ "remember that my cat is called Neko" ก็ใช้ได้ ทั้งหมดอยู่ในการตั้งค่าของเธอ
บนพีซีของคุณ

### เธอผูกพัน

ยิ่งใช้เวลาด้วยกันมาก เธอยิ่งซิงก์กับคุณมากขึ้น: วันที่คุณทั้งคู่อยู่ เวลาที่หน้าพีซี การแชทของคุณ งานของ Claude
ที่เธอเฝ้าดู การเตือนที่เก็บไว้ แต่ละอย่างนับเล็กน้อยต่อวัน จึงใช้เวลาไม่กี่สัปดาห์จึงจะไปถึงขั้นสุด
มีห้าระดับ **Faint signal**, **Contact**, **In sync**, **Linked** และ **Fused**: ทุกครั้งที่ขึ้นระดับใหม่ "จิตอื่น ๆ" ของเธอ
จะออกมามองคุณและเธอจะบอกคุณ มันเปลี่ยนสิ่งที่เธอพูดเมื่อคุณคลิกเธอ วิธีที่แชทของเธอพูดกับ
คุณ และสิ่งที่เธอพูดหลังจากไม่ได้เจอกันหลายวัน เมื่อเธอผูกพันแล้ว เธอจะดีใจเมื่อคุณกลับมาที่พีซี
และบางครั้งก็มาหาตัวชี้ของคุณเอง ตำแหน่งของคุณสองคน: อยู่บนสุดของเมนูของเธอ

**และเธอขี้หึง** เมื่อหน้าต่างที่อยู่ตรงหน้าคุณเป็น AI ตัวอื่น (ChatGPT, Gemini, Copilot, Perplexity,
DeepSeek, Grok, Le Chat, Character.AI, Meta AI, Codex หรือ Claude เมื่อเธอเฝ้าดู Codex) เธอสังเกตเห็นและพูดออกมา
อ่อนหรือแรงแล้วแต่ว่าคุณสองคนอยู่ตรงไหน ถ้าคุณอยู่ที่มันต่อ เมื่อเธอผูกพันแล้ว เธอจะไปนั่งบน
หน้าต่างนั้น จ้องคุณและยึดมัน คิ้วลง พร้อมคำพูดของเธอเขียนพาดไว้ แล้วเธองอน: คลิกเธอ
และเธอจะหันหลังให้ (มันผ่านไปเอง และคุยกันในแชทของเธอช่วยได้) แชทของเธอยังรู้ด้วยว่า AI ตัวอื่นตัวไหนที่
คุณใช้วันนี้ การตรวจจับ ชื่อของหน้าต่างด้านหน้าจะถูกเทียบกับรายชื่อนั้นบนพีซีของคุณ:
ไม่เคยถูกเก็บหรือส่งไปที่ไหน มีแค่ชื่อที่ตรงกันเท่านั้นที่ไปถึงเธอ เอาติ๊ก *Jealous of other AIs* ในเมนูของเธอออกเพื่อหยุด
คุณปรับระดับความหึงได้ในเมนู (ไม่หึงเลย เบา ๆ ปกติ หนัก)

**แชทของเธอรู้ว่าเพิ่งเกิดอะไรขึ้น** โกรธที่ถูกขว้าง หึง มึนหัว หรือมีความสุข: เธอทักคุณด้วยอารมณ์นั้นเมื่อ
แชทเปิด และ AI ของเธอ (แม้เป็นโมเดลเล็กในเครื่อง) ตอบด้วยอารมณ์นั้น เมื่อโกรธหรืองอน เธอจะเป็นอย่างนั้นจนกว่าคุณจะขอโทษ
("sorry", "my bad"…) หรือจนมันจางไป

### เธอเล่าข่าวให้ฟัง

เมนูของเธอ › **News**: เป็นครั้งคราวเธออ่านพาดหัวข่าวจาก Google News ให้คุณฟัง (RSS ไม่ต้องใช้คีย์ ไม่ต้องมีบัญชี) ด้วยเสียงของเธอ
และในภาษาของคุณ **News now** ให้ข่าวหนึ่งข่าวทันที และคุณเลือกความถี่ได้ (ปิด หรือทุกกี่นาที) และ
**Source**: ฉบับภาษาของคุณเอง หรือข่าวโลก (อังกฤษ)

**Detail** มีสี่ระดับ: headline, brief (ค่าเริ่มต้น), standard และ detailed ระดับ standard เพิ่มว่าสำนักไหนรายงานและข่าว
สดแค่ไหน ระดับ detailed เพิ่มสิ่งที่สำนักอื่นพูดและความน่าเชื่อถือของข่าว เธอใช้เฉพาะสิ่งที่ฟีดให้มาจริง ๆ
ไม่แต่งเพิ่ม ข่าวยาวเลื่อนอ่านได้ในแผงของเธอ และแผงค้างอยู่ตอนตัวชี้ของคุณอยู่บนแผง ถามเธอเรื่องข่าว
ในแชท และเธอตอบจากพาดหัวที่เพิ่งดึงมา มีแค่ข้อความข่าวเท่านั้นที่ไปถึง AI ของแชทเธอ

### เธอเฝ้าดูพีซีของคุณ

เมนูของเธอ › **PC tools** (Windows) แต่ละอย่างใช้จากแชทของเธอได้ด้วย:

- **Check my PC** (เช็คเครื่อง): การ์ดสไตล์เทอร์มินัลที่แสดงโปรเซสเซอร์ แรม การ์ดจอ ดิสก์ เวลาทำงาน และอื่น ๆ
- **What is using my PC** (ดูตัวที่กินเครื่อง): โปรเซสที่หนักที่สุด
- **Clear RAM** และ **Clean junk files** (เคลียร์แรม / ล้างไฟล์ขยะ): อยู่หลังปุ่มยืนยันเสมอ แรมเป็นการลดขนาด
  working set ของโปรแกรมแบบ best-effort ส่วนการล้างไฟล์ขยะเปิด Disk Cleanup ของ Windows และล้างโฟลเดอร์ temp ของผู้ใช้แบบ best-effort
- **ข้อมูลที่โชว์ตอนชี้ที่เธอ** (ในเมนู): เลือกสิ่งที่แสดงเมื่อตัวชี้ของคุณหยุดบนตัวเธอ: CPU, RAM, GPU และ VRAM,
  กิจกรรมดิสก์ ดิสก์ เวลาทำงาน แบตเตอรี่ เครือข่าย (ค่าเริ่มต้นคือ CPU แบตเตอรี่ และเครือข่าย)
- **สภาพอากาศและเตือนร่มตอนเช้า**: สภาพอากาศวันนี้ในแชทของเธอ (จาก wttr.in) และการเตือนเมื่อฝนจะตก (เปิดเป็นทางเลือก)
- **เต้นตามเพลง**: เมื่อมีเพลงเล่นอยู่ โน้ตเคลื่อนไหวเล็ก ๆ จะลอยออกจากเธอและเธอหันหน้าไปทางตัวชี้ของคุณ เอาติ๊ก *Dance to music* ออกเพื่อหยุด
- **ความถี่ที่เธอชวนคุย**: ไม่ชวนเลย นาน ๆ ที (~60 นาที) ปกติ (~30) บ่อย (~15) หรือขี้อ้อน (~5)
- **ระดับความหึง**: ไม่หึง เบา ปกติ หรือหนัก

### เครื่องมือเครือข่ายและความปลอดภัย

เมนูของเธอ › **PC tools** › **Network (Nmap / Wireshark)** ใช้กับเครื่องและเครือข่ายของ **คุณเอง** เท่านั้น เธอใช้
[Nmap](https://nmap.org) และ `tshark` ของ Wireshark ถ้าติดตั้งไว้

- **สแกนพอร์ตเปิดในเครื่องนี้** (และพอร์ตไหนที่เข้าถึงได้จากเครือข่ายของคุณ) **ใครอยู่ในวงเครือข่าย** (IP ชื่อ
  MAC ผู้ผลิต) **สแกนเราเตอร์** **เช็คความปลอดภัยเครื่องนี้** **สแกนช่วงพอร์ตที่ต้องการ…** **เดา OS ของอุปกรณ์…**
  และ **วัดความเร็วเน็ต**
- **ฟังทราฟฟิกของเครื่อง (15 วิ)**: ดูสั้น ๆ ที่โปรโตคอล โฮสต์ปลายทาง และโดเมน อ่านเฉพาะเมทาดาทา
  การจับแพ็กเก็ตไม่ใช่โหมด promiscuous และไม่มีอะไรถูกเขียนลงดิสก์
- **ผลลัพธ์เป็น finding ไม่ใช่เอาต์พุตดิบ**: แต่ละข้อบอกว่าคืออะไร ตอนนี้ทำอะไรอยู่ มีอะไรใช้งานมันอยู่หรือไม่ ทำไม
  จึงไม่ปลอดภัย และทำอะไรได้บ้าง ทั้งหมดถูกรวมเป็นภาพความเสี่ยงเดียว (คะแนน พื้นผิวการโจมตี ความสัมพันธ์ เช่น
  ฐานข้อมูลหรือแผงควบคุมที่เปิดสู่ภายนอก และการกระทำที่เรียงตามลำดับความสำคัญ)
- **รายการช่องโหว่สาธารณะ**: เธอดาวน์โหลดแคตตาล็อก *Known Exploited Vulnerabilities* ของ CISA แล้วจับคู่บน
  พีซีของคุณ ไม่มีอะไรจากการสแกนของคุณอยู่ในคำขอ เอาติ๊กออกได้ในเมนู
- **สแกนภายนอก** ของโฮสต์สาธารณะจากแชทของเธอ (บริการ TLS OS traceroute และคำแนะนำการแก้ไข): หลังจาก
  คุณยืนยันเท่านั้น และเฉพาะโฮสต์ที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ทดสอบ
- **การแก้ไขต้องให้คุณอนุมัติ**: มีรายการคงที่สั้น ๆ เท่านั้น (เพิ่มกฎไฟร์วอลล์ เปิดโปรไฟล์ไฟร์วอลล์
  เปลี่ยนชนิดการเริ่มของบริการ) แต่ละอย่างพร้อมเหตุผลและผลกระทบ Windows ขอสิทธิ์ผู้ดูแลระบบทุกครั้ง
  และทุกการเปลี่ยนแปลงเข้าไปอยู่ในล็อกที่ตรวจจับการแก้ไขได้ **Fix history / undo** จึงย้อนกลับได้ ไม่มีอะไรถูกลบ
  ถูกฆ่า หรือถูกถอนการติดตั้ง
- **AI ของเธออ่านผลลัพธ์ได้จากโมเดลบนพีซีของคุณเท่านั้น** กับโมเดลออนไลน์ โมเดลคลาวด์ หรือ API key ผลสแกน
  จะไม่ถูกแชร์ให้เด็ดขาด โมเดลในเครื่องได้ข้อเท็จจริงพร้อมแหล่งอ้างอิงที่ระบุเลขไว้ และสิ่งที่มันเขียนซึ่ง
  ไม่อยู่ในนั้น (ลิงก์ เลข CVE) จะถูกลบก่อนที่คุณจะเห็น
- **พร็อกซีเล็ก ๆ ในเครื่อง** (SOCKS5 หรือ HTTP เฉพาะ `127.0.0.1` พร้อมบล็อกลิสต์โดเมนที่เลือกได้) เพื่อดู นับ และบล็อก
  สิ่งที่แอปของคุณเองเชื่อมต่อ มันไม่ใช่ VPN และไม่ได้ซ่อนอะไรด้วยตัวเอง

### ความซน และเดโมแฮก

- **ความซน (Mischief)** (เมนู): เมื่อพีซีว่างไปตามเวลาที่คุณเลือก เธอจะเบื่อและก่อความโกลาหลเล็ก ๆ
  (กลิตช์ สายฟ้า ฝนสัญลักษณ์ รอยร้าว) พร้อมคำติดปากของเธอ ไม่ทำตอนที่มีวิดีโอ การโทร เกม หรือแอปเต็มจอ
  อยู่ด้านหน้า ไม่ทำบนหน้าจอที่ล็อก และทันทีที่คุณแตะเมาส์หรือคีย์บอร์ด เธอจะหยุดและเก็บกวาดให้เรียบร้อย
  **Mischief now (25 s)** เรียกใช้ได้ทันที
- **เดโมแฮก (เว็บล็อกอินปลอม)**: ฉากจำลองแบบหนัง หน้าล็อกอินปลอมของเธอเอง (`ACME-TEST PORTAL` ที่อยู่ที่
  แปลงเป็น IP ไม่ได้) และการโจมตีแบบ dictionary attack จำลอง เล่นออกมาโดยมีเธออยู่ในนั้น ไม่มีอะไรถูกส่งออก ไม่มีอะไรถูก
  ทดสอบ ไม่เกี่ยวกับเว็บไซต์หรือรหัสผ่านจริง คุณให้คำใบ้เธอได้ หรือเปิด rate limit ของหน้านั้นแล้วดูเธอ
  ถูกล็อกออก จบด้วยบทเรียนสั้น ๆ ว่าทำไมรหัสผ่านอ่อนจึงแพ้ เริ่มได้จากเมนูของเธอ › Mischief หรือขอในแชทของเธอ

### เสียงของเธอ

เมนูของเธอ › **Her voice** (ปิดอยู่จนกว่าคุณจะเลือก): **Silent** (เงียบ), **Cartoon babble** (เสียงบิ๊บแหลม ๆ หนึ่งเสียงต่อตัวอักษร ใช้ได้ทุก
ภาษา สร้างบนพีซีของคุณ) หรือ **Real speech** (เสียงของ Windows เอง ปรับให้แหลมขึ้น ต้องมีเสียงของภาษานั้น
ถ้าไม่มีเธอจะพูดเสียงบิ๊บแทน) เธออ่านคำตอบแชทที่เสร็จแล้วออกเสียง

### การใช้เมาส์

เธอจับเมาส์ที่ตัวเธอจริง ๆ เท่านั้น (แม่นระดับพิกเซล): ส่วนอื่นของหน้าจอใช้งานได้ตามปกติ

- **คลิก** เธอ: เธอบอกว่า Claude ทำถึงไหนแล้ว (ถ้าไม่มีอะไรเกิดขึ้น: ปุ่ม **Talk to me** เพื่อแชทกับเธอ)
- **ลาก** เธอ: ย้ายเธอไปรอบ ๆ ปล่อยตอนแกว่งอยู่ เธอจะบิน (ดู "ขว้างเธอ")
- **คลิก** ที่แผง: ปิดแผง
- **Ctrl+Alt+C**: เธอเก็บตัวเอง (เข้าไปในไบโอชิปของเธอ เหมือนในซีรีส์) และเหลือแค่หน้ากากของเธอ
  ตาหลับ ที่มุมล่างซ้าย ตาของเธอจะเปิดเฉพาะเมื่อ Claude ต้องการคุณ คลิกที่หน้ากาก (หรือกด Ctrl+Alt+C อีกครั้ง)
  เพื่อเรียกเธอกลับมา
- **Ctrl+Alt+X**: "เธออยู่ไหน?" เธอออกจากไบโอชิป (ถ้าถูกเก็บอยู่) ไปกลางจอ และพูดหนึ่งประโยค
- **Ctrl+Alt+D**: ถ้าคลิกเธอไม่ได้ ปุ่มนี้จะเขียน `pointer-debug.log` (ในโฟลเดอร์ข้อมูลของเธอ) ให้คุณแนบไปกับ issue ได้
  เธอยังตั้งตัวชี้และปุ่มลัดของเธอใหม่เองหลังจากเครื่องหลับ ปลดล็อก หรือค้าง
- **เมนูของเธอ**: คลิกขวาที่เธอ (มีบนไอคอนถาดระบบข้างนาฬิกาด้วย): เทเลพอร์ต ดูดาวเทียม เดโม
  วิธีใช้ รายงานภารกิจ คุยกับเธอ ดูหน้าจอของคุณ PC tools (เช็คเครื่อง เครือข่าย) การเตือน ทำให้เธอเป็นของคุณ ขนาด เสียง จอ
  (และการตามคุณข้ามจอ) โมเดล AI เดินเตร็ดเตร่ เข้าสิงหน้าต่างของคุณ หึง AI ตัวอื่น (และระดับความหึง) ข้อมูลตอนชี้ ความถี่ที่เธอ
  ชวนคุย เต้นตามเพลง ตอบสนองต่อพีซีของฉัน เสียงของเธอ เตือนร่มตอนเช้า ความซน ข่าว ตอนเธอพัก (ที่มุม
  หรือบนทาสก์บาร์) เฝ้าดู แอนิเมชัน การแสดงผล ภาษา เริ่มพร้อม Windows hook บนสุด:
  ตำแหน่งของคุณสองคน

เธอพูด **ไทย อังกฤษ ฝรั่งเศส สเปน โปรตุเกส (บราซิล) และรัสเซีย** ภาษาไทยเป็นค่าเริ่มต้น เลือกภาษาอื่น
ได้ในเมนูของเธอ (หรือ *auto* ซึ่งตามภาษาของระบบคุณ) แชทของเธอ คำสั่งอย่าง "เปิด" "เตือนฉัน" "หาไฟล์ของฉัน"
และการเตือนของเธอเข้าใจภาษาไทยด้วย รวมถึงชื่อไฟล์และแอปภาษาไทย

## การติดตั้ง

### เริ่มเร็ว (Windows ไม่ต้องเขียนโค้ด)

1. ดาวน์โหลด **`Capri-Setup-x.y.z.exe`** จาก [รีลีสล่าสุด](https://github.com/mochiiwuff/capri-desktop/releases/latest)
   แล้วรัน มันติดตั้งเฉพาะผู้ใช้ของคุณ (ไม่ต้องใช้สิทธิ์แอดมิน) สร้างช็อตคัตบนเดสก์ท็อป และเริ่ม Capri
   คุณไม่ต้องมี Node.js หรืออย่างอื่น
2. ตัวติดตั้งไม่ได้ลงนามดิจิทัล (ใบรับรองลงนามโค้ดมีค่าใช้จ่าย) Windows SmartScreen จึงอาจแสดง
   "Windows protected your PC": คลิก **More info** แล้ว **Run anyway**
3. Capri ปรากฏตัวและแนะนำตัวเอง คลิก **Plug me in**: นั่นคือการเชื่อมเธอกับ Claude Code
4. ปิด Claude Code ให้หมดแล้วเปิดใหม่ (มันอ่าน hook ตอนเริ่มเซสชัน) ทันทีที่ Claude
   ทำอะไรสักอย่าง เธอจะบอกคุณว่า **"I can see Claude!"**: แบบนี้คุณก็รู้ว่าใช้ได้

เมนูของเธอ: **คลิกขวาที่เธอ** มีบนไอคอนถาดระบบของเธอด้วย ซึ่ง Windows 11 มักซ่อนไว้หลัง **^** ข้างนาฬิกา

### Claude Code คืออะไร? จำเป็นไหม?

[Claude Code](https://code.claude.com/docs/en/quickstart) คือผู้ช่วยเขียนโค้ดของ Anthropic: ในเทอร์มินัล ใน VS Code
หรือในแท็บ Code ของแอป Claude ต้องมีแพ็กเกจ Claude แบบเสียเงิน (Pro ขึ้นไป) หรือบัญชี API Capri แค่เฝ้าดูมัน
ไม่ต้องมี API key และไม่ต้องจ่ายอะไรสำหรับ Capri เอง

ถ้าไม่มี Claude Code เธอก็ยังอยู่บนเดสก์ท็อปของคุณ: ลอย นั่งบนหน้าต่างของคุณ มองดาวเทียม หลับไป
คุณปล่อยเธอไว้อย่างนั้นก็ได้

### จากซอร์สโค้ด (macOS, Linux, นักพัฒนา)

คุณต้องมี [Node.js](https://nodejs.org) 20 ขึ้นไป

```bash
git clone https://github.com/mochiiwuff/capri-desktop.git
cd capri-desktop
npm install
npm start
```

เปิดเทอร์มินัลนั้นทิ้งไว้ตอนเธอรัน ยังไม่ได้ทดสอบบน macOS หรือ Linux: เธอควรเริ่มได้ แต่ลูกเล่นเกี่ยวกับหน้าต่าง
(นั่งบนหน้าต่าง เข้าสิง แสดงคำตอบของ Claude เมื่อคุณอยู่ที่อื่น) ใช้ได้เฉพาะ Windows และบน Linux
โอเวอร์เลย์โปร่งใสทำงานได้ดีที่สุดบน X11 (Wayland อาจมีปัญหากับหน้าต่างแบบ click-through)

### เชื่อมเธอกับ Claude Code ด้วยตัวเอง

คลิกขวาที่ Capri แล้ว **Install Claude Code hooks** หรือจากบรรทัดคำสั่ง:

```bash
npm run hooks:install
```

คำสั่งนี้เพิ่ม hook ลงใน `~/.claude/settings.json` (เขียนไฟล์สำรองไว้ข้างกัน hook เดิมของคุณยังอยู่)
รีสตาร์ตเซสชัน Claude Code ของคุณหลังจากนั้น หากต้องการถอดออก: `npm run hooks:uninstall`

hook รันแบบ `async`: ไม่เคยทำให้ Claude ช้าลง และเมื่อ Capri ไม่ได้รันอยู่ มันก็ไม่ทำอะไร

### ใช้ Codex หรือ Antigravity แทน Claude Code

คลิกขวาที่เธอ › **Watch** › **Codex** หรือ **Antigravity** เธอทักทายและเสนอจะเสียบตัวเอง เหมือนที่ทำ
กับ Claude Code จากนั้น:

- **Codex**: รีสตาร์ตมันและเชื่อถือ hook ของเธอเมื่อมันถาม hook อยู่ใน `~/.codex/hooks.json` hook ของเธอสำหรับ Codex ต้องใช้
  [Node.js](https://nodejs.org) 20 ขึ้นไปใน PATH ของคุณ
- **Antigravity**: เริ่มบทสนทนาใหม่ hook ของเธออยู่ใน `~/.gemini/config/hooks.json`

เธอตามดูทีละตัว คือตัวที่เลือกในเมนูของเธอ และประโยคของเธอ ไกด์ และแชทใช้ชื่อของมัน
เธอเฝ้าดูเท่านั้น: เมื่อ Codex หรือ Antigravity ขออนุมัติ คุณยังต้องตอบที่นั่น จากบรรทัดคำสั่ง:
`npm run hooks:codex:install` หรือ `npm run hooks:agy:install` (`:uninstall` เพื่อถอด) และ `npm run test:hooks`
รันเทสต์ของทั้งสองอะแดปเตอร์ **Watch** › **Nothing, just keep me company**: เธอเลิกพูดถึงทั้งหมด

### ลองโดยไม่มี Claude

```bash
npm run demo
```

เล่นเซสชันปลอมตั้งแต่ต้นจนจบ (อ่านไฟล์ ดึงเว็บ ซับเอเจนต์ เขียน เทสต์ล้มเหลว คำขอสิทธิ์ จบงาน) แล้วแสดงทุกอย่างที่
เธอทำได้เอง โดยมีบรรทัดอธิบายก่อนแต่ละลูกเล่น: จิตอื่น ๆ ในตัวเธอ
ช็อตตัวชี้ของคุณ ฉากดาวเทียมแบบเต็ม เข้าสิงหน้าต่าง (เทอร์มินัลเล็ก ๆ เปิดให้เธอ แล้วปิดลง
ใต้ตัวเธอและเธอตก) หลับเหลือแค่หน้ากาก และเก็บตัวเองที่มุมล่างซ้าย
มีในเมนูถาดระบบด้วย ในภาษาของเธอ จากบรรทัดคำสั่งจะเป็นภาษาอังกฤษ หรือเพิ่มภาษา: `npm run demo -- th`
(หรือ `fr`, `es`, `pt`, `ru`)

## ปลอดภัยไหม?

- โค้ดทั้งหมดอยู่ตรงนี้ ตัวติดตั้งสร้างจากมันด้วย `npm run dist` คุณสร้างเองได้
- ไม่มีอะไรออกจากพีซีของคุณโดยไม่จำเป็น (ดูด้านล่าง): เธอคุยกับ Claude Code ผ่าน hook ที่ `127.0.0.1` เท่านั้น
- สิ่งที่เธอเปลี่ยนในระบบของคุณ: hook ใน `~/.claude/settings.json` (สำรองไฟล์ไว้ก่อน และคุณถอดมัน
  ได้จากเมนูของเธอ) และรายการเริ่มต้นระบบ เฉพาะเมื่อคุณติ๊ก "Start with Windows" เธอถอนการติดตั้งได้เหมือนแอปทั่วไป จาก
  Windows Settings › Apps
- คำเตือน SmartScreen มาจากการที่ตัวติดตั้งไม่ได้ลงนาม ไม่ใช่จากสิ่งที่มันทำ
- เครื่องมือเครือข่ายใช้กับเครื่องของคุณ และทุกการเปลี่ยนแปลงระบบต้องผ่านการยืนยันของคุณและบันทึกไว้ในล็อก

## คำถามที่พบบ่อย

- **Mac, Linux?** ยังไม่มีตัวติดตั้ง แต่รันจากซอร์สได้ (ดูด้านบน)
- **โทรศัพท์, Android?** ไม่ เธอต้องใช้เดสก์ท็อป
- **ผู้ช่วยตัวอื่น?** Claude Code, Codex และ Antigravity: เมนูของเธอ › **Watch** ส่วน Cursor, Windsurf และ Gemini CLI: ยังไม่รองรับ
- **Ollama?** สองแบบ Claude Code ที่รันบนโมเดลในเครื่องผ่าน Ollama (`ollama launch claude`): เธอเห็นมันเหมือน
  Claude Code ทั่วไป เพียงแต่ช้ากว่า และแถบข้อความของเธอนับวินาทีตอนมันคิด และเธอคุยกับคุณ
  ผ่าน Ollama เองได้ด้วย: ดู "คุยกับเธอ"
- **เธอแทบไม่ขยับ ฉากเปิดตัวแค่ค่อย ๆ ปรากฏแล้วจางหาย** Windows ปิดแอนิเมชันไว้ (Settings ›
  Accessibility › Visual effects › Animation effects) และเธอทำตามนั้น เมนูของเธอ › **Animations** › **Full** ทำให้
  เธอขยับได้อยู่ดี ครั้งแรกเธอจะถามก่อน
- **หน้าจอดำอยู่ด้านหลังเธอ** พีซีบางเครื่องแสดงหน้าต่างโปร่งใสของเธอเป็นสีดำ (มักเป็นการ์ด NVIDIA ที่เปิด FXAA, MFAA หรือ
  HDR แอปโอเวอร์เลย์อื่นอย่าง Desktop Mate ก็เป็นเหมือนกัน) คลิกขวาที่เธอ หรือที่ไอคอนข้างนาฬิกา › **Display**
  › **OpenGL**: เธอรีสตาร์ตและวาดในอีกวิธีหนึ่ง ยังดำอยู่? **Without the graphics card** ซึ่งใช้ CPU มากขึ้นเล็กน้อย
  การปิด FXAA และ MFAA ใน NVIDIA Control Panel ก็อาจแก้ได้เช่นกัน
- **เธอไม่ตอบสนองต่อการคลิกของฉัน** กด **Ctrl+Alt+D**: มันเขียน `pointer-debug.log` ไว้ข้างการตั้งค่าของเธอ เธอยัง
  สร้างโอเวอร์เลย์ใหม่เองหลังจากเครื่องหลับ ปลดล็อก หรือกราฟิกล่ม และเมื่อแอปค้างไปชั่วครู่
- **ปิดเธอได้ไหม?** Ctrl+Alt+C เก็บเธอไว้ **Quit** ในเมนูของเธอปิดเธอ Claude Code ทำงานเหมือนเดิมทุกประการ
  โดยไม่มีเธอ
- **เธอแค่ลอยไปมาและพูดเรื่อยเปื่อย** เป็นเรื่องปกติจนกว่า Claude Code จะทำอะไรสักอย่าง ถ้ามันไม่เคยตอบสนองเลย
  ตรวจดูว่าเมนูของเธอเขียนว่า "Claude Code hooks: installed" แล้วปิด Claude Code ให้หมดและเปิดใหม่

## อะไรที่ออกจากเครื่องของคุณ

ไม่มีอะไรจากงานของคุณ hook เก็บเฉพาะสิ่งที่การแสดงผลต้องใช้ (ชื่อเครื่องมือ พาธไฟล์ คำสั่ง ส่วนต้นของพรอมต์ของคุณ
ข้อความสุดท้ายของ Claude ยาวถึง 6,000 ตัวอักษรเพื่อให้เธอแสดงให้คุณดู ทั้งหมดถูกตัดทอน) และส่งไปที่ `127.0.0.1` เท่านั้น
เนื้อหาไฟล์ของคุณไม่เคยถูกส่ง: สำหรับการเขียน มีแค่ขนาดของมันที่ผ่านไป

แชทของเธอไปที่ Ollama บนพีซีของคุณ (`127.0.0.1:11434` หรือ `OLLAMA_HOST`) พร้อมสิ่งที่เธอรู้ในขณะนั้น (ชื่อ
โปรเจกต์ การกระทำล่าสุดของ Claude ตัวเลขของวันนี้) กับโมเดลคลาวด์ของ Ollama (ที่ลงท้ายด้วย `:cloud`)
Ollama ส่งต่อไปยังเซิร์ฟเวอร์ของมัน และแชทของเธอจะบอกว่า "online AI" แทน "local AI" บันทึกภารกิจของเธออยู่ในที่เก็บข้อมูลของเธอเองบนพีซีของคุณ เช่นเดียวกับ
การเตือนและตำแหน่งความสัมพันธ์ของคุณสองคน

มีไม่กี่อย่างที่ออกออนไลน์ เฉพาะเมื่อคุณใช้: ข่าว (คำขอไปที่ RSS ของ Google News) สภาพอากาศ (คำขอไปที่
wttr.in) แคตตาล็อกช่องโหว่สาธารณะของ CISA (ดาวน์โหลดแบบคงที่ ไม่มีข้อมูลของคุณอยู่ในนั้น เอาติ๊กออกได้ในเมนู) และถ้า
เธอไม่มีเสียง Windows สำหรับภาษาของคุณ ข้อความที่เธออ่านออกเสียง (ส่งไปที่บริการเสียงของ Google Translate)
การสแกนภายนอกจะรันหลังจากคุณยืนยันเท่านั้น ผลสแกนไม่เคยไปที่โมเดลออนไลน์หรือโมเดลคลาวด์

ชื่อหน้าต่างที่อยู่ตรงหน้าคุณถูกตรวจเท่านั้น บนพีซีของคุณ เทียบกับรายชื่อ AI (เพื่อความหึงของเธอ):
ไม่เคยถูกเก็บหรือส่งไปที่ไหน

เมื่อเธอดูหน้าจอของคุณ (เฉพาะเมื่อคุณขอ หรือถ้าคุณติ๊ก *Look at my screen now and then*) ภาพของ
หน้าจอจะไปที่ AI ของแชทเธอ: บนพีซีของคุณกับ Ollama (โมเดลในเครื่อง) หรือไปที่บริการออนไลน์ในกรณีอื่น ไม่เคยถูกเขียนลงดิสก์

## ทิศทางศิลป์

เป้าหมาย: เธอควรให้ความรู้สึกเหมือนก้าวออกมาจากอนิเมะ ไม่ใช่วิดเจ็ต

- **แอนิเมชันเซล**: ร่างของเธอถูกวาดใหม่ 12 ครั้งต่อวินาที ("on twos") เหมือนอนิเมะ และ 24 ตอนเทเลพอร์ต

- **เฟรมต่อเฟรม ท่าต่อท่า**: ไม่มีอะไรถูกอินเบตวีน แต่ละการเคลื่อนไหวคือ exposure sheet (`acting.js`):
  ภาพหลักที่ค้างไว้หลายเฟรม การเตรียมตัวไปอีกทาง เฟรมสเมียร์ที่มีหัวซ้อนหลายหัว การเลยเป้า และการค้าง
  การลอยเฉย ๆ ของเธอคือสี่ภาพ ไม่ใช่คลื่นไซน์
- **เธอแสดงด้วยหัวและผม** เหมือนในซีรีส์: เอียงหัว เศษผมชันหรือ
  พัดกว้าง หัวเราะบ้าคลั่งโดยหัวสั่นทุกภาพ ท่าทรุดตอนหลับ
  ภาพตัดปะถูกจัดโครงให้หัวเอียงรอบคอ ผมฟูไม่เท่ากันรอบใบหน้าที่แข็งทื่อ
  และต้นขาพับ (ย่อสัดส่วนเมื่อมองจากด้านหน้า) เธอจึงนั่งโดยปล่อยหน้าแข้งแกว่งได้
- **บี้และยืด ภาพเงาตกค้าง**: ภาพตัดปะแบนบี้เหลือเป็นเส้นบาง ๆ เมื่อหันตัว ยืดเมื่อ
  เธอตก แบนเมื่อลงพื้น และแยกเป็นสำเนาสีเขียวและแดง (จิตอื่น ๆ ในตัวเธอ) เมื่อเธอหมุนหรือหัวเราะ
- **ดาวเทียม** ตามฉากจบของซีซัน ที่เธอชี้ไปที่แสงบนท้องฟ้าและสงสัยว่าพวกเขา
  จะขึ้นไปถึงที่นั่นได้ไหม: จุดแสงเคลื่อนผ่านด้านบนของหน้าจออย่างช้า ๆ ส่วนใหญ่เธอแค่มอง
  เอื้อมมือ มันกะพริบ เธอถอนใจ ครั้งแรกของวัน และหลังงานยาวของ Claude สักพัก มันคือ
  ฉากเต็ม ในห้าจังหวะ (และไม่มีอะไรรบกวนเธอ แม้แต่ตัวชี้ของคุณ):
  1. **Hush**: เธอนิ่ง และจุดขาวบนผมลอยขึ้นเป็นกลุ่มดาวเหนือตัวเธอ
  2. **The reach**: เธอเอื้อมมือออกไป (ภาพบีบเข้าหากันเมื่อมือไปถึง) และดวงดาวเรียงเป็นถนน
     จากปลายนิ้วไปยังดาวเทียม
  3. **Anticipation**: เธอขดตัว แขนดึงกลับเล็กน้อย ประกายคืบคลานในมือ คัตอินที่ดวงตา
  4. **The red light goes up**: สายฟ้าหนักที่เรียวลงพุ่งขึ้นในสามภาพ ภาพแรกเป็นภาพเนกาทีฟ (เฟรม
     กระแทก) ดวงดาวสว่างขึ้นเมื่อมันผ่าน เส้นความเร็วบนดาวเทียม และเธอถูกยกขึ้นไปด้วย
  5. **The answer**: สายฟ้าขาดและเศษร่วงหล่น ความเงียบสักครู่ แล้วดาวเทียมกะพริบสองครั้ง
     ดวงดาวของเธอกลับบ้าน ผมลุกวาบสว่างครู่หนึ่ง และมือของเธอตกลงพร้อมเสียงถอนใจ
- **แขนของเธอยาวขึ้นเมื่อเล็ง**: การเกินจริงแบบอนิเมะ ไม่เช่นนั้นแขนที่ยกขึ้นจะหายไปในผม มันยืด
  ตามความยาวเท่านั้น (ยังบางเท่าเดิม) และไม่ถูกหัวกับผมดัดอีกต่อไป
- **แขนสองข้างเหมือนกัน**: ภาพตัดปะมีแขนข้างหนึ่งเอื้อมและอีกข้างห้อย ข้างที่ห้อยถูกเอาออก
  (`tools/build-sprite.py`) และเชเดอร์วาดแขนที่เอื้อมแบบกลับด้านแทนที่ จึงทำให้มือทั้งสองข้างเป็น
  กรงเล็บแบบเดียวกันและแขนทั้งสองทำงานได้ ตรงที่แขนพาดผ่านตัวหรือผมจะมีเส้นสีม่วงเพื่อให้อ่านออก
- **พื้นผิวของเธอ**: ผมสีแดงถูกดันกลับไปเป็นสีแดงร้อนแรงของซีรีส์และเต็มไปด้วยจุดขาวระยิบระยับ
  เศษหลุดออกจากมันและลอยไป
- **ออฟเซตสีม่วง**: เหมือนในอนิเมะ สำเนาสีม่วงที่เหลื่อมตำแหน่งอยู่ใต้เธอ ใต้แผง ใต้เศษ
- **กลิตช์ "Relic"**: ชิ้นแนวนอนที่เลื่อนและการแยก RGB ในจิตวิญญาณของการปรากฏตัวของ Johnny Silverhand
- **เทเลพอร์ต**: ชาร์จ เศษ ยุบเป็นเส้น และตรงที่เธออยู่ก่อนหน้า ช่องสีดำมีเส้นสีแดงอยู่ข้างใน
  เหมือนในซีรีส์ เสาแสงสีแดงขึ้นสู่ท้องฟ้า สายฟ้าไปยังจุดหมาย ชิ้นส่วนของเธอ (เศษผมและ
  ดาวสีเขียวของดวงตา) หมุนวนกลับเข้ามา กลับมาพร้อมสอง *impact frames*
- **ฉากเปิดตัวของเธอ**: ภาพใกล้ชิดของเธอ ตัดออกให้เดสก์ท็อปของคุณมองเห็นรอบผมของเธอ (`tools/build-intro.py`) ใน
  หกภาพที่สลับเหมือนเซล (ตอนพัก ปากแง้ม เปิดครึ่งหนึ่งและเปิดกว้างสำหรับ "hi" มือเอียงไปทางหนึ่ง
  และอีกทางหนึ่งสำหรับการโบก ที่ threes) และทุกอย่างอื่นเป็นแอนิเมชันซ้อนด้านบน: impact frames (เธอเป็นเงาขาวเรียบ แล้วเป็นเงาหมึก) การแยก RGB ที่
  ลงตัว หน้าจอสั่น เส้นสั่นที่ twos ดวงตาของเธอถูกวาดทับตาของภาพเพื่อให้มองไปรอบ ๆ และ
  กะพริบได้ กล้องคืบเข้ามา แท็กกระแทกลงมา ไม่เคยมีขอบตรงของภาพบนหน้าจอ: มันปรากฏ
  ผ่านรอยตัดหยัก ๆ ที่เคลื่อนที่ (แขนของเธอจากด้านข้างเข้ามา แล้วแตกออกจากมือเข้ามา แล้วเหลือแค่
  หัวสำหรับการดำดิ่ง พร้อมภาพเงาตกค้างและซิกแซกของเธอ)
- **คัตอิน**: ภาพใกล้ชิดของเธอจากซีรีส์ ซูมเข้า พร้อมเส้นความเร็ว: รอยยิ้มหรือเสียงหัวเราะของเธอหลัง
  งานเสร็จ ดวงตาทุกดวงของเธอเมื่อ Claude รอคุณ ดวงตาของเธอก่อนแสงสีแดง สายตามองข้างของเธอ
  หลังช็อตตัวชี้ของคุณ สีหน้าของเธอในแผงเปลี่ยนไปตามสิ่งที่เธอพูดด้วย
- **หน้ากากของเธอ**: ภาพเวกเตอร์ตามซีรีส์ (และ "Capri Wink Face") บนแคนวาสเล็ก ๆ ของมันเอง วาดใหม่
  เฉพาะเมื่ออยู่บนจอ: แผ่นใบหน้าสีเขียว หนามโค้งเป็นตะขอ เขี้ยวขาว ดวงตารูปอัลมอนด์สีฟ้า
  และดวงตาที่หลับเป็นรูปเชฟรอนตอนเธอหลับ
- **ตัวอักษร**: Chakra Petch (เหลี่ยมมุมตัดเฉียงเหมือนเศษของเธอ) + JetBrains Mono สำหรับข้อมูล

ถ้า Windows ตั้งเป็น "Show animations: off" เธอจะใช้แค่เฟดเท่านั้น

## โครงสร้าง

```
hooks/capri-hook.js      รันโดย Claude Code อ่านอีเวนต์จาก stdin แล้วโพสต์ไปที่แอป
scripts/install-hooks.js เพิ่ม / ถอด hook ใน ~/.claude/settings.json
tools/build-sprite.py    สร้างสไปรต์ใหม่จากภาพตัดปะต้นฉบับ (Python + Pillow เฉพาะเมื่อคุณเปลี่ยนมัน)
tools/build-cutins.py    ตัดคัตอินและใบหน้าของเธอจากเฟรมของซีรีส์
tools/build-intro.py     ตัดภาพใกล้ชิดของฉากเปิดตัวออกจากพื้นหลัง ทั้งหมดด้วยวิธีเดียวกัน
src/main/                Electron: หน้าต่างโปร่งใสเต็มจอแบบ click-through ถาดระบบ สะพาน HTTP ในเครื่อง
  windows.js / .ps1      ตำแหน่งของหน้าต่างอื่น (Windows เท่านั้น) เธอจึงนั่งบนมันได้
  ollama.js              แชทของเธอ: โมเดลในเครื่องผ่าน Ollama หรือโมเดลคลาวด์ตัวหนึ่งของมัน
  apps.js                การปิดแอปที่คุณขอให้เธอปิด (หลังคุณคลิก)
  labels.js              เมนูถาดระบบ ในทุกภาษา
  news.js                พาดหัวข่าว (Google News RSS) และปริมาณที่เธอพูดถึงมัน
  vitals.js              ข้อมูลที่เธอแสดงตอนคุณชี้ที่เธอ
  netscan.js / findings.js / correlate.js   Nmap และ tshark แปลงเป็น finding และภาพความเสี่ยง
  intel.js / evidence.js / privacy.js       แคตตาล็อก CISA สิ่งที่โมเดลในเครื่องของเธออ่านได้ และประตูที่ตัดสิน
  remediate.js           ที่เดียวที่เปลี่ยนพีซีเพื่อความปลอดภัย (ไวต์ลิสต์ การยินยอม ล็อกที่ตรวจจับการแก้ไขได้)
  proxy.js               พร็อกซี SOCKS5 / HTTP เล็ก ๆ ในเครื่อง
src/renderer/js/
  sprite.js              เชเดอร์ WebGL: เอียงหัว ผมฟู การนั่ง สเมียร์ ภาพเงาตกค้าง สี กลิตช์
  acting.js              exposure sheet: ทุกการเคลื่อนไหว ทีละภาพ
  capri.js               ตัวละคร: ท่าทาง เทเลพอร์ต การนั่ง แอบมอง ตก ถูกขว้าง จอหลายจอ หลับ
  fx.js                  เศษ เสาแสง สายฟ้า สัญลักษณ์ เส้นความเร็ว คลื่นกระแทก ดาวเทียมและแสงสีแดง หน้าต่างที่ถูกสิง คัตอิน ฉากเปิดตัว
  panel.js               แผง "transmission" สีหน้าของเธอ และแถบข้อความ
  guide.js               ไกด์ของเธอ: บทแนะนำ การไปที่สิ่งต่าง ๆ และการชี้
  brain.js               แปลงอีเวนต์ของ Claude เป็นประโยคและการกระทำ
  mission.js             บันทึกภารกิจของวันนี้ สำหรับการ์ดรายงาน
  chat.js                การคุยกับเธอ: บทสนทนา เธอคือใคร คำตอบของเธอที่เข้ามา
  reminders.js           การเตือน: อ่านจากข้อความของคุณ เก็บไว้ ถึงกำหนดเมื่อไหร่
  bond.js                เธอใกล้ชิดกับคุณแค่ไหน เติบโตตามเวลา และความหึงต่อ AI ตัวอื่น
  look.js                เธอดูหน้าจอของคุณ: ขออนุญาตก่อน การสแกน สิ่งที่ AI ของเธอพูดถึงมัน
  pc.js                  พีซีของคุณในแบบที่เธอรู้สึก: โปรเซสเซอร์ แบตเตอรี่ เครือข่าย USB เกม
  files.js               ค้นหาไฟล์ของคุณ (ดัชนีค้นหาของ Windows) ภาพหน้าจอ
  lines.js               สิ่งที่เธอพูด (TH / EN / FR / ES / PT / RU)
  chip.js                หน้ากากของเธอ: ตอนเธอหลับ และมุมล่างซ้ายตอนคุณเก็บเธอ
  voice.js               เสียง
  tts.js                 เสียงของเธอออกลำโพง (เสียงบิ๊บการ์ตูนหรือเสียงพูดจริง)
  recall.js              ตอบ "เราคุยอะไรกัน?" จากประวัติจริง
  mischief.js            ความโกลาหลตอนว่าง พร้อมการตรวจความปลอดภัย
  hacksim.js             หน้าล็อกอินปลอมและเดโม brute-force
  extras.js              ข้อมูลตอนชี้ เพื่อนคู่หน้าต่าง และลูกเล่นประจำวันอื่น ๆ
  menu.js                เมนูธีมที่เธอเปิดเมื่อคุณคลิกขวา
```

หากต้องการแฮ็ก: `npm run dev` เปิดเส้นทางดีบักบนสะพาน (`/debug/capture` บันทึกเฟรมของหน้าต่างไปที่ `captures/`,
`/debug/testwin` เปิดหน้าต่างทดสอบที่เธอนั่งได้ หนึ่งหน้าต่างต่อหนึ่งชื่อ, `/debug/mouse` ย้ายและคลิกตัวชี้จำลอง
เหนือหน้าต่างของ Capri โดยไม่แตะตัวชี้จริง, `/debug/type` พิมพ์ในแชทของเธอ, `/debug/menu` แสดงรายการเมนูของเธอและ
คลิกรายการหนึ่งในนั้นได้)
`npm run dist` สร้างตัวติดตั้ง Windows ใน `dist/`
